# SatelliteQ
SatelliteQ
An open-source Fiji–Python workflow for multidimensional quantification of centriolar satellite properties.
SatelliteQ enables object-based analysis of centriolar satellites in 2D images, 3D Z-stacks and time-lapse microscopy datasets. It quantifies satellite number, size, fluorescence intensity, shape and spatial organization, including centrosome distance, spatial entropy and the pericentrosomal clustering index.

Getting started
1. Install Fiji and the required plugins.
2. Install Python and the dependencies specified in requirements.txt.
3. Run the SatelliteQ Fiji macro on a microscopy image.
4. Open the Fiji results using the SatelliteQ Python program to generate reports and interactive visualizations.
