# ============================================================================
# IMPORTANT: OTHER REQUIREMENTS (not pip-installable; do not add below)
# ============================================================================
# 1. Fiji / ImageJ, version 1.53 or newer, is required to run the .ijm macro.
#    Download: https://fiji.sc/
# 2. For 3D satellite analysis install the SEPARATE Fiji plugin:
#       3D Objects Counter+
#    Fiji -> Help -> Update -> Manage update sites -> Add Unlisted Site
#       Name: 3DObjectsCounterPlus
#       URL: https://sites.imagej.net/3DObjectsCounterPlus/
#    Apply changes; restart Fiji; check Analyze -> 3D Objects Counter+.
#    Do not confuse this with the built-in original 3D Objects Counter.
# 3. Optional cilium quantification uses Fiji's Skeletonize (2D/3D) and
#    Analyze Skeleton commands (normally present in current Fiji builds).
# 4. Bio-Formats and local thresholding are supplied by a standard updated Fiji
#    installation. Verify the relevant commands in Fiji before analysis.
# 5. tkinter is part of a Python installation WITH Tk/Tcl, not a pip package:
#       python -m tkinter
#    The command should display a test window. On a Mac, if it does not work,
#    use a Tk-enabled python.org installation; on Linux, your distribution
#    may require its separate python3-tk operating-system package.
# 6. A modern graphical browser is needed to view interactive HTML outputs.
#    The generated Plotly HTML embeds the viewer code for local viewing.
# 7. Have enough free disk space for raw images, intermediate Fiji data and
#    Python reports. 3D stacks and time-lapse series can require considerable
#    memory; RAM needs depend on image size and Z/T depth.
# 8. The Fiji and Python V26 scripts are SEPARATE programs. Installing these
#    Python requirements does not install or configure Fiji plugins.
